HOW TO TEST
================================================================================

1. Run unit tests:
   pip install -e .[dev]
   pytest tests/ -v

2. Run with coverage:
   pytest tests/ --cov=voice_agent --cov-report=html

3. Check formatting:
   black --check voice_agent

5. Type check:
   mypy voice_agent --ignore-missing-imports

   GROQ_API_KEY=your_key
   VOICE_AGENT_GROQ_ENABLED=true
   python -m voice_agent.main
